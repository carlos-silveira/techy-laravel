# Authentication Controllers

These controllers are primarily boilerplate generated by Laravel Breeze or Jetstream, handling the standard authentication lifecycle.

## Controllers
- `AuthenticatedSessionController.php`: Handles logging in and out. Validates credentials and regenerates the session token.
- `RegisteredUserController.php`: Handles new user registration (if public registration is enabled). Hashes passwords and creates the `User` model.
- `PasswordResetLinkController.php` & `NewPasswordController.php`: Manage the "Forgot Password" flow via email links.
- `VerifyEmailController.php` & `EmailVerificationPromptController.php` & `EmailVerificationNotificationController.php`: Handle email verification steps after registration.
- `ConfirmablePasswordController.php`: Requires the user to re-enter their password for sensitive actions.

## Context for AI Agents
When modifying auth logic, agents should rarely touch these files unless adding new fields to the registration form or modifying the post-login redirect path.
