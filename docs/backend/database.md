# Database & Models

TechyNews uses MySQL 8.0+ as its primary data store. The database schema is designed to support the extensive content generation capabilities of the platform, with a focus on speed and multi-lingual support.

## Core Models

### `Article`
The `Article` model is the central entity. It represents a single news story, whether it's a draft generated by AI or a published piece.

**Key Columns:**
- `title` (string): The headline of the article.
- `slug` (string): SEO-friendly URL identifier.
- `summary` (text): A short excerpt or summary generated by the AI.
- `content` (longtext): The full body of the article stored as **raw HTML**. Storing raw HTML maximizes rendering speed by eliminating the need for complex parsing on the frontend.
- `translations` (json): A JSON column used to store localized versions of the title, summary, and content.

### `Category` & `Tag`
Articles can be categorized and tagged to improve discoverability.

## Important Rules for Content Storage

1. **No JSON Encoding for Content**: NEVER use `json_encode()` on HTML content strings before storing them in the `content` column.
2. **Raw HTML**: Always store article content as raw, valid HTML.
3. **Translation Overrides**: When an article is requested in a different language, the system checks the `translations` JSON column. If the translation exists, it overrides the default language fields.
