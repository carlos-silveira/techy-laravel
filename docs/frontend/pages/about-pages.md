# About, Privacy, and Terms

These are static, informational pages delivered via Inertia.

## `About.jsx`
Serves a dual purpose in TechyNews:
1. Explaining the ethos of the AI-native CMS.
2. Acting as a developer portfolio.
- **Design:** Uses heavy Framer Motion animations for a premium, award-winning visual impact (parallax scrolling, text reveals).

## `Privacy.jsx` & `Terms.jsx`
Standard legal documents.
- **Content:** Stored directly in the React components as Markdown-like JSX structures. 
- **Styling:** Wrapped in `@tailwindcss/typography` (`prose`) classes to ensure high readability without manual CSS targeting.
